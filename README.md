# Rimpa Adventist Comprehensive School (RACS) Website

Official multi-page website for **Rimpa Adventist Comprehensive School (RACS)**, located in Rimpa, Kajiado County, Kenya.

> **Motto:** Ready To Shine  
> **Philosophy:** Education For Eternity

---

## 🌟 Key Features

* **Modern Responsive Interface:** Clean, mobile-friendly design crafted with vanilla HTML5, modern CSS3 (Flexbox, CSS Grid, Glassmorphism), and JavaScript.
* **Hero Experience:** High-impact hero section with organic wave transition, glassmorphism badges, and smooth scroll guidance.
* **Instant Client-Side Search:** Real-time keyword lookup mapping terms across the entire website.
* **Complete School Portals:**
  * **Admissions & Fees:** Step-by-step admissions walkthrough, fee schedule, other common charges, extra-curricular fees, and payment channel guidelines.
  * **Student Life:** Weekly meal menu, 7-zone transport fees with pick-up areas, school uniform price guide, and co-curricular programs (French and Swimming lessons).
  * **About & Gallery:** School vision, mission, why choose RACS pillars, and categorized photo galleries (Facilities, People/Staff, Life at School).
  * **Academics:** Curriculum overview and academic calendar/timetable previews.

## 🚀 Getting Started

No build tools or package managers required. Simply open `index.html` in any modern web browser or serve via a local static server:

```bash
# Using Python
python -m http.server 8000

# Or using VS Code Live Server extension
```
